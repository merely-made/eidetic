# responsa

Answers to design questions, kept as cases in the words given, linked by
typed fields lines and reconciled into a doctrine of short statements by
area, kept to a budget. Responsa are jurists' written answers to questions
put to them, which accrued into law.

`responsa regen [--stage]` writes a repository's manifest and case register
and folds its git history into a link journal; `check` reports a stale
manifest, the doctrine's budget overruns and links into sibling repositories
that do not resolve; `lookup` answers for a case, a plan's decision, a
statement, another repository's key or a path. The rules it keeps are a
repository's `DOC_POLICY.md`, core section 11.
