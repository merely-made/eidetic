# Source splits: H6 Eidetic batch

**Status (2026-11-03):** landed; 15/15 paths qualified.

This is the second fifty-file pass under Mere's house-style plan, H6.
The eight earlier splits and all fifty H5 paths are excluded. Mark's
"Another batch?" continues the same qualification rule: an original counts
only after it and all new modules fit 600 physical lines, its exact ceiling
exception is retired, appropriate tests and local gates pass, and the change
is committed and pushed. Ordinary private implementation and fixture moves
need no new design ruling. Public API paths, owner authority, source data,
file formats, arithmetic, test assertions and feature boundaries stay intact.

The retained receipt cap is 100 MB across both repositories and Mere's
aggregate. Only compact summaries are retained; failed baseline findings are
recorded explicitly. Frozen receipts, imported patches and captured fixtures
remain unchanged. This pass supplies software/compiler evidence and does not
renew native-device, headed, radio, audio-quality or other-platform claims.

## Phases and done-conditions

- **S1. Graph, retained models and storage.** Separate Chartulary commit/spine
  implementation and fixture groups; isolate page/answer model helpers and
  directory transaction responsibilities. Preserve replay, operation ordering,
  atomic publication, revision and ownership/error boundaries.
- **S2. Search, update and capability gates.** Separate lexical search and
  recall fixtures, updater/install helpers and Servitor delegation/gate/run
  groups. Keep typed failures, cancellation, capability checks, signed-feed
  admission and public facade paths. Standalone tooling stays independent.
- **S3. Portable drop and comparison fixture.** Separate native-drop regression
  cases and the inventory comparison model. Existing record bytes, integrity
  checks, limits, scenario order and deterministic seeds remain intact.
  Live group/session integration remains in its existing ownership lane.

Each phase is complete when original files and children fit 600 physical
lines, exact exceptions retire, scoped baseline/post tests and feature/docs
checks pass, and the full local gate plus actual commit hook pass. Count
only published source. Root workspace tests do not include the standalone
Responsa or line-ceiling workspaces; this pass does not modify those tools.
